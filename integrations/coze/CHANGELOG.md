# Changelog

本文件记录 `integrations/coze/` 的公开变更，按时间倒序排列。

## 2026-10-13

### Fixed

- 补齐执行辅助模块的 `time` 导入，修复 `remaining_seconds()` 使用默认时钟时的 `NameError`；增加未显式传入 `now` 的回归测试，覆盖剩余时间计算和已过期预算归零。

## 2026-10-12

### Added

- 增加按 Coze 目录及工作流自身路径过滤的 CI，在拉取请求和 main 分支更新时从仓库根目录运行锁定依赖的 Python 3.13 测试；支持手动触发，不使用业务凭证或调用收费接口。

## 2026-10-10

### Added

- 建立国内站和国际站的独立配置模型，分别绑定工作空间、服务密钥和允许的 Skill 能力。
- 增加 `GET /healthz` 健康检查、固定工具路由约定、服务密钥认证、能力授权、统一错误响应和追踪 ID。
- 增加工作空间只读检查脚本，可分别验证两个站点的配置、令牌和 `listWorkspace` 权限。
- 增加锁定的 Python 依赖及可复现的配置、认证、路由和错误边界回归测试。
- 增加受控 HTTPS 文件下载、限时产物元数据、持久化任务记录、请求去重、租约恢复、超时辅助和有界并发／限流组件。
- 增加步骤 4 的文件、任务、超时和限流专项回归测试。

### Changed

- 明确服务使用 HTTPS、站点隔离和服务端凭证边界；平台令牌不作为普通插件调用参数传递。
- 任务重启恢复将未完成的运行中任务标记为 `submission_unknown`，不自动重新提交可能产生副作用的操作。
- 将用户文档整理为配置、启动、健康检查和 Coze 接入说明，移除开发过程、测试取证和个人账号信息。
- 将开发阶段的 Skill 盘点、样本生成脚本、账号核查记录和本地样本保留在 Git 忽略目录，不作为公开运行依赖。

### Not available yet

- 业务 Skill 适配、对应 OpenAPI 文档、产物 HTTP 路由、完整长任务工作流，以及插件创建／发布管理操作将在相关能力完成并经过验证后加入公开版本。

# Changelog

本文件记录 `integrations/coze/` 的公开变更，按时间倒序排列。

## Unreleased

### Changed

- 配置检查、OpenAPI 导出、部署检查和产物地址使用同一套 HTTPS 域名／代理前缀校验规则。
- 后台队列仅领取保留输入的本地合同／GIF 任务；任务结果与上游映射统一经带租约校验的保存接口写入。
- 明确由使用方或团队管理员自行部署后端，承担域名／证书、业务凭证、存储维护及调用费用；同一实例可服务单站或双站。
- 补齐自有工作空间创建插件、部署记录归属、产物地址配置及域名变更说明；配置示例与使用指引保持一致。
- 插件通过官方控制台导入、调试、更新和发布，由部署方按需申请商店上架。
- 将部署指引整理为服务器准备、域名和证书配置、启动检查及维护步骤，集中说明两份配置文件和需要填写的值。
- 明确工作空间发布、公开商店分发和功能开发的不同完成条件；商店插件固定绑定部署地址，使用服务认证和部署方统一讯飞用量，当前授权按站点／工作空间划分，开放范围与持续服务由部署方落实。
- Coze CI 在 Python 3.13 和 3.14 上分别运行锁定依赖的测试。
- 明确限时产物下载不要求服务密钥、不受工作空间限流保护，以及基础请求日志的范围；说明输入保留 24 小时且不随任务提前失败而删除。

### Added

- 增加独立 Docker Compose 部署、后端镜像、HTTPS 代理和部署说明，支持自有证书、可配置端口及私有数据目录；凭证和运行数据保存在部署环境。
- 增加按站点执行的部署检查命令与回归，直接连接并验证 HTTPS、健康检查、认证和工具路由，可选检查内置发音人列表；不使用系统／环境代理、不创建任务、不调用收费上游、不跟随重定向或输出敏感配置。
- 部署检查增加 `--all-tools`，验证本站全部已授权工具的路由／参数及非收费发音人列表；训练文本查询工具显式使用无效参数，避免误触发上游请求。
- 增加双站控制台接入与发布说明，覆盖 11 项 Skill 的调试流程、文本／异步示例、同址更新、域名迁移和商店准备；补齐 DNS、端口、证书续期、故障排查及全量 GIF 的 Linux 直接运行部署说明。
- 增加视频阶段映射、字幕确认／去重、额度失败后恢复、跨站隔离和完成产物要求的离线回归。
- 增加从已注册路由和接口模型导出的 11 份 OpenAPI 3.0.3 JSON 规范，覆盖全部 24 个工具、Header 服务认证和统一错误响应。
- 增加规范导出／一致性检查命令，支持独立站点或显式后端地址；实际部署规范默认输出到 Git 忽略目录。
- 补充工具、参数、响应及异步任务说明；正确转换可空类型、常量、排他边界和引用附加说明，增加独立规范校验及 HTTP 契约回归。
- 接通 11 个 Skill 的 24 个工具，增加具体请求／响应模型、原始脚本适配、独立子进程执行与限时产物下载。
- 接通持久化本地任务执行、上游任务查询、创建／阶段操作去重和工作空间归属；声音样本上传与训练提交分开，合成校验资源归属。
- 合同流程复用原规则处理器，增加实际 OCR、图像理解、翻译和 Spark 审核客户端，支持报告格式选择及必要阶段失败传播。
- 增加受限 HTML 渲染容器、固定镜像 ID、无网络／无凭证执行和资源限制；缺少运行环境时关闭渲染能力。
- 增加适配器、任务流程、完整流式结果、文件格式和渲染边界回归测试。

### Fixed

- 部署检查将损坏或截断的 HTTP 响应记录为脱敏失败结果，避免直接退出或输出原始响应。
- 调整部署代理等待时间和容器临时存储容量，使其覆盖媒体操作预算与默认并发；同步更新部署和节点超时说明。
- 恢复任务 GET 查询的 `job_id` 格式校验及规范约束，补充全部任务查询接口的 HTTP／规范一致性回归。
- 视频工具说明与当前运行时保持一致：成功后才返回输出，待确认阶段不返回字幕内容；同步重新生成规范。
- 修复本地任务租约到期时二次保存异常终止后台队列的问题；拒绝迟到结果并标记 `failed/TIMEOUT`，后续任务继续处理。
- 确保后台任务异常后关闭服务仍释放单实例锁，允许同一数据目录再次启动。
- 产物地址提前拒绝无效端口、内网主机名、平台 API 域名和重复路由前缀，避免生成不可用的下载地址；错误提示不包含配置值。
- 视频兼容原客户端的待字幕审核状态，翻译审核单独标为待输入并拒绝错误的字幕确认，已取消的上游任务不再无限显示运行中。
- 修正规范转换中可空分支与外层约束合并时可能放宽限制的问题，保留组合约束；不支持的组合结构明确拒绝。
- 导出命令拒绝单独使用 `--env-file`，避免误生成示例规范；配置或后端地址错误提供不含敏感值的具体提示。
- 文件下载连接到已验证的 IP，保留 TLS 主机名验证，禁用环境代理并逐次校验重定向；修正文件大小错误分类并关闭 SQLite 连接。
- 产物文件复制移至 SQLite 写事务之前，事务内保留容量检查、文件发布及元数据写入；补充并发容量和失败清理回归测试。
- 任务租约到期拒绝迟到写入，取消和重启后保留远程提交不确定状态。
- 修正图片 OCR 签名 Host、校对请求 Host 和转写分片尾块；TTS／图片理解必须收到结束帧，拒绝把部分输出当成功结果。
- 声音训练改用 HTTPS 并拒绝重定向，克隆合成启用证书验证；超时不回退到不安全传输。
- 按实际接口修正图片 OCR 的 Markdown 请求与结果提取；PDF 已知 CDN 产物使用 HTTPS 转存，隐藏原始输入地址并复用重复链接。
- 极速转写限制为官方支持的自动识别参数组合；声音训练校验采样率、时长、声道和 WAV 位深，提前拒绝不合规录音。
- 视频额度不足映射为明确的配额错误；已确认的权限／配额拒绝不再标为受理不确定，阶段操作保留父任务可恢复状态。
- 强化合同模型的原文引用要求，将无法匹配的证据降级为人工复核项，保留其他有效结果和报告；渲染构建上下文排除凭证、样本和运行数据。
- 训练失败明确标记已知的音频／文本不匹配原因，隐藏服务商私有字段；渲染支持常用语言和 UTF-8 元数据，并约束 FFmpeg 线程数以适配容器资源限制。
- 视频等待字幕确认时不重复转存输出；音视频输入和产物下载的单文件预算为 180 秒，相关调用总预算为 600 秒，租约相应延长至 660 秒。回归覆盖 128 MiB 流式转存、慢调用保存及完成后重复轮询。
- 本地任务维护清理降为 30 秒间隔，空队列轮询不再获取写锁；重启或租约到期时将本地任务标记为 `failed/TIMEOUT`。校验 GIF 实际帧数并修正大文件上传的 multipart 文件名。

### Removed

- 删除任务存储中未使用的续租、上游标识和完成／失败快捷接口，以及合同模型客户端未使用的逐条分析／摘要方法和字段。

### Validation

- 锁定依赖的 Python 3.13／3.14 完整测试各 248 项通过，11 份 OpenAPI 3.0.3／24 个工具的一致性及静态检查通过。
- 后端和 HTTPS 代理镜像已从当前源码实际构建，并使用 Compose 验证启动、双站认证、生产依赖、权限限制、产物下载及重启后的任务／文件持久化和去重；使用本地测试证书及合成数据，不调用收费上游。

### Availability

- 明确声音训练通过服务端文本与段落 ID 选择录音内容，当前工具不支持用自定义转写替换训练文本。
- 本地后台任务一次处理一个作业；队列上限和 900 秒排队期限决定了实际吞吐，生产部署应据此控制提交量。
- 声音复刻已使用匹配训练文本的录音完成训练、克隆合成和音频下载的实际验证；各能力仍需确认部署账号的权限及业务结果。
- OpenAPI 3.0.3 已支持导出和校验；各部署在两站分别完成控制台导入、调试和发布，离线校验不代表平台验收。

## 2026-10-13

### Fixed

- 补齐执行辅助模块的 `time` 导入，修复 `remaining_seconds()` 使用默认时钟时的 `NameError`；增加未显式传入 `now` 的回归测试，覆盖剩余时间计算和已过期预算归零。

## 2026-10-12

### Added

- 增加按 Coze 目录及工作流自身路径过滤的 CI，在拉取请求和 main 分支更新时从仓库根目录运行锁定依赖的 Python 3.13 测试；支持手动触发，不使用业务凭证或调用收费接口。

## 2026-10-10

### Added

- 建立国内站和国际站的独立配置模型，分别绑定工作空间、服务密钥和允许的 Skill 能力。
- 增加 `GET /healthz` 健康检查、固定工具路由约定、服务密钥认证、能力授权、统一错误响应和追踪 ID。
- 增加工作空间只读检查脚本，可分别验证两个站点的配置、令牌和 `listWorkspace` 权限。
- 增加锁定的 Python 依赖及可复现的配置、认证、路由和错误边界回归测试。
- 增加受控 HTTPS 文件下载、限时产物元数据、持久化任务记录、请求去重、租约恢复、超时辅助和有界并发／限流组件。
- 增加步骤 4 的文件、任务、超时和限流专项回归测试。

### Changed

- 明确服务使用 HTTPS、站点隔离和服务端凭证边界；平台令牌不作为普通插件调用参数传递。
- 任务重启恢复将未完成的运行中任务标记为 `submission_unknown`，不自动重新提交可能产生副作用的操作。
- 将用户文档整理为配置、启动、健康检查和 Coze 接入说明，移除开发过程、测试取证和个人账号信息。
- 将开发阶段的 Skill 盘点、样本生成脚本、账号核查记录和本地样本保留在 Git 忽略目录，不作为公开运行依赖。

### Not available yet

- 业务 Skill 适配、对应 OpenAPI 文档、产物 HTTP 路由及完整长任务工作流将在相关能力完成并经过验证后加入公开版本。

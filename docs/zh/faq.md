# FAQ

新手上手时常见问题的合集。缺了某个问题？欢迎帮我们补充——参见 [为文档站做贡献](/zh/contribute-to-docs)。

## 我需要哪些凭证？

大多数技能使用讯飞开放平台的三元组：`XFEI_APP_ID`、`XFEI_API_KEY`、`XFEI_API_SECRET`。在
[控制台](https://console.xfyun.cn/) 创建应用并复制其 APPID / APIKey / APISecret。参见
[快速开始](/zh/guide/quick-start#_2-获取凭证)。

## 我遇到鉴权或「服务未开通」错误

每项能力（TTS、OCR、翻译……）可能需要为应用 **单独开通**，且各有独立配额。请在控制台打开对应能力，
确认它已在你所用 APPID 的应用下开通。

## 需要安装依赖吗？

大多数技能仅基于 Python **标准库** 编写，无需 `pip install`。若某个技能需要额外依赖，其 `SKILL.md`
会注明。

## 凭证应该放在哪里？

放在环境变量里，不要写进代码。技能从环境读取 `XFEI_APP_ID` / `XFEI_API_KEY` / `XFEI_API_SECRET`。
切勿将凭证提交到 fork，或粘贴到 issue / PR 中。

## 如何知道某个技能怎么调用？

打开该技能的 `SKILL.md`。frontmatter 说明何时使用，正文记录确切的脚本、参数与示例命令。
[技能列表](/zh/skills/) 链接到每个技能。

## 我的任务该用哪个技能？

- 识别图片或 PDF → **PDF / 图片 OCR**；提取结构化发票字段 → **发票 OCR**。
- 文本转语音 → **超拟人语音合成**；先克隆特定音色 → **声音克隆**。
- 音频转写 → **极速语音转写**。
- 翻译文本 → **机器翻译**；翻译/配音视频 → **视频翻译**。
- 中文文本校对 → **文本纠错**。
- 端到端审核整份合同 → **合同智能审核**。

## 可以在自己的智能体中使用这些技能吗？

可以。每个技能都是带触发描述的自包含能力包，既可注册到支持技能的智能体运行时，也可在你自己的工作流中直接调用其脚本。

## 如何参与贡献？

新增技能、用法示例、翻译或 FAQ 条目——参见 [贡献指南](/zh/CONTRIBUTING) 与开放的
[贡献 issue](https://github.com/iflytek/iFly-Skills/issues)。

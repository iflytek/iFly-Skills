# 概览

**iFly-Skills** 是 [科大讯飞 (iFLYTEK)](https://www.xfyun.cn/) 面向智能体生态系统和开发者工作流的官方
AI 技能集合。它将讯飞的 AI 能力——语音、OCR、翻译、校对、多模态理解——封装为自包含、可复用的技能，
易于安装、组合与演进。

## 什么是「技能 (Skill)」？

每个技能是仓库中一个独立的顶层目录，打包了智能体调用该能力所需的一切：

```
ifly-hyper-tts/
├── SKILL.md        # 触发描述、API 文档、使用示例
├── scripts/        # 可运行脚本（优先使用 Python 标准库）
└── _meta.json      # 元数据
```

`SKILL.md` 的 frontmatter 告诉智能体「何时」触发该技能（`description` 与 `user_instructions`），
正文则说明「如何」调用。大多数技能仅依赖 Python 标准库，几乎无需安装。

## 两类技能

- **原子技能**：封装单一模型能力——文本转语音、OCR、翻译等。
- **解决方案技能**：将多种能力串联为一个场景级任务流，例如
  [合同智能审核](/zh/skills/#solutions)（OCR → 条款分析 → 风险检测 → 校对 → 摘要）。

技能集合将持续向更多面向场景的能力包扩展：文档处理、内容生产、智能审核、多模态分析以及其他综合任务链。
